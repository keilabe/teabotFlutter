# Firebase Configuration for Service Worker

This project uses an automated approach to manage Firebase configuration for the service worker, ensuring consistency between your Flutter app and web service worker.

## How it works

1. **Source of Truth**: The Firebase configuration is defined in `lib/firebase_options.dart` (generated by FlutterFire CLI)
2. **Auto-Generation**: A Node.js script (`scripts/update-firebase-config.js`) extracts the web configuration and generates `web/firebase-config.js`
3. **Service Worker**: The service worker (`web/firebase-messaging-sw.js`) imports the generated configuration

## Usage

### Automatic (Recommended)
```bash
# Update Firebase config and build web
npm run build-web

# Or update config only
npm run update-firebase-config

# Or build and deploy in one command
npm run deploy
```

### Manual
```bash
# Update Firebase configuration from Flutter options
node scripts/update-firebase-config.js

# Build Flutter web app
flutter build web

# Deploy to Firebase
firebase deploy
```

## Files

- `lib/firebase_options.dart` - Source Firebase configuration (auto-generated by FlutterFire CLI)
- `scripts/update-firebase-config.js` - Script to extract and generate web config
- `web/firebase-config.js` - Generated Firebase configuration for service worker
- `web/firebase-messaging-sw.js` - Service worker that uses the generated config

## Why this approach?

Service workers cannot directly access `.env` files or build-time environment variables. This approach:

1. ✅ Keeps configuration in sync between Flutter app and service worker
2. ✅ Automates the process to prevent manual errors
3. ✅ Uses the official FlutterFire CLI configuration as the source of truth
4. ✅ Works with Firebase hosting deployment

## Updating Configuration

When you update your Firebase project settings:

1. Run `flutterfire configure` to update `lib/firebase_options.dart`
2. Run `npm run update-firebase-config` to regenerate the web config
3. The service worker will automatically use the new configuration

## Troubleshooting

If you get configuration errors:

1. Check that `lib/firebase_options.dart` contains valid web configuration
2. Run `npm run update-firebase-config` to regenerate
3. Verify `web/firebase-config.js` contains the correct values
4. Clear browser cache and reload the page
